## Track Legend

The indoor test arena uses:
- **White insulation tape** — dual lane lines on glossy marble floor
- **Blue circular signs** — directional arrows (left, right, straight)
- **Red STOP sign** — triggers TSR hard stop
- **Smartphone** — displays traffic light image for TLR testing

All images are referenced in [`../../walkthrough.md`](../../walkthrough.md).
